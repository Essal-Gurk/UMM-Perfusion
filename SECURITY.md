# Security and sensitive information

For a security issue, use the repository's private vulnerability-reporting
feature when available. If it has not been enabled, ask the maintainer for
a private reporting channel before disclosing technical details publicly.
Repository administrators can enable private vulnerability reporting in
the GitHub security settings.

Include the affected plugin/IsiX/macOS versions and a synthetic
reproduction. Exclude patient data, credentials and database exports.

Support is on a best-effort community basis. This release has no promised
security-response or clinical-support service.
