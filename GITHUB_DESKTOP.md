# Publish with GitHub Desktop

This folder is a local Git repository with the source and precompiled plugin
already committed on branch main.

1. In GitHub Desktop, choose File → Add Local Repository.
2. Select this folder, UMM-Perfusion.
3. Choose Publish repository.
4. Select your GitHub account and repository visibility, then publish.

If GitHub Desktop already lists UMM-Perfusion, select it from Current
Repository and choose Publish repository.

When using the ZIP, extract it first and select the extracted UMM-Perfusion
folder. Keep its hidden .git directory with the rest of the files.

The release ZIP and checksums are available separately in Release-assets
inside the full GitHub-ready package. Attach them to a v0.4.1 GitHub Release
after publishing the repository.
